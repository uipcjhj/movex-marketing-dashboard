현대무벡스 디지털 마케팅 대시보드 MVP

실행 방법
1. 현대무벡스_마케팅_대시보드.html을 다운로드합니다.
2. Chrome 또는 Edge 최신 버전으로 파일을 엽니다. 설치나 서버 실행이 필요 없습니다.
3. 기본 화면은 2026년 10월 샘플 실적입니다.
4. 데이터 관리에서 샘플_업로드.csv를 선택하고 검증 후 반영합니다.
5. 기간을 11월로 변경하면 업로드한 실적을 볼 수 있습니다.
6. 콘텐츠 일정에서 일정 추가/수정/삭제가 가능합니다.
7. 보고서 다운로드는 독립 HTML 파일입니다. 열어서 인쇄 > PDF로 저장할 수 있습니다.

주의: 모든 초기 데이터는 가상 샘플입니다. 회사 내부 데이터를 사용하지 않았습니다.
현재 브라우저의 localStorage에 저장됩니다. 같은 파일 위치, 같은 브라우저로 사용하세요.
파일 이동, 시크릿 모드, 브라우저 데이터 삭제 시 저장 데이터가 유지되지 않을 수 있습니다.
데이터 관리 > 데이터 백업으로 CSV를 보관하세요. 일정은 현재 브라우저에 저장됩니다.

업로드 형식
CSV(UTF-8) 또는 Excel .xlsx, 최대 5MB/10,000행, 첫 번째 시트만 읽습니다.
필수 열: 월, 채널, 조회노출, 참여, 팔로워증가
월은 YYYY-MM 텍스트, 채널은 유튜브/링크드인/인스타그램입니다.
수치는 0 이상의 정수이며 같은 월/채널의 실적을 대체합니다.
오류가 한 행이라도 있으면 반영을 차단합니다. Excel의 월 셀은 텍스트로 지정하세요.
구형 .xls, 암호화된 Excel, 수식 계산, 날짜 일련번호는 지원하지 않습니다.

지표 정의
유튜브 조회수 / 링크드인·인스타그램 노출수. 채널별 정의가 달라 합계는 운영 참고용입니다.
참여는 월별 입력 건수, 팔로워 증가는 월별 순증 입력값입니다.
전월 증감은 선택 월과 직전 달 비교. 전월 0 또는 데이터 없음은 비교 불가/없음 표시.
연간 누적을 선택하면 전월 비교를 생략합니다.
연간 목표는 데모 고정값: 유튜브 180만 / 링크드인 120만 / 인스타그램 150만.
연간 달성률은 월 필터와 관계없이 선택 연도의 누적 실적으로 계산합니다.
샘플 실적: 2025년 12개월, 2026년 1~10월. 미집계 월은 차트를 연결하지 않습니다.

기술 구성
설치 의존성이 없는 HTML/CSS/JavaScript. 차트는 SVG.
XLSX는 ZIP/XML과 브라우저 DecompressionStream으로 처리하며 외부 서버로 파일을 보내지 않습니다.
소스의 repository.js는 UI와 저장 계층을 분리합니다.
향후 listRecords/listEvents/importRecords/saveEvent/deleteEvent 계약을 유지한 HTTP 저장소로 교체 가능합니다.
API 인증/서버 저장/동기화는 이번 MVP에 포함되지 않습니다.

개발용 실행
소스 ZIP을 풀고 dist 폴더에서 python3 -m http.server 8000 실행 후
http://localhost:8000 에 접속합니다. 종료는 Ctrl+C입니다.
Python이 없어도 제공한 단일 HTML은 바로 열 수 있습니다.

검증
13개 자동 검증 통과: 샘플 구성, CSV 파싱/검증, 중복 및 오류 차단,
월·채널 대체/멱등성, 합계/증감률, 저장 복원, 일정 수정/삭제, 저장 실패 시 보존.
JavaScript 구문 검사 통과.
현재 환경의 브라우저 제어 및 배포 실행 파일을 사용할 수 없어
실제 브라우저 클릭 테스트, 반응형 화면 실측 및 XLSX 브라우저 해제 검증은 미완료입니다.
온라인 배포 URL은 제공하지 않습니다.
