# 현대무벡스 디지털 마케팅 대시보드 MVP

모든 초기 실적과 일정은 가상의 샘플입니다. 실제 회사 내부 데이터가 아닙니다.

## Windows에서 다운로드하고 실행하기

1. 이 파일이 보이는 브랜치에서 **Code → Download ZIP**을 선택합니다.
2. ZIP을 마우스 오른쪽 버튼으로 클릭하고 **모두 압축 풀기**를 선택합니다.
3. `downloads/현대무벡스_마케팅_대시보드.html`을 Chrome 또는 Edge로 엽니다.
4. 데이터 관리에서 `downloads/샘플_업로드.csv`를 선택하고 검증 후 반영합니다.
5. 기간을 2026년 11월로 바꾸면 가져온 샘플 실적을 확인할 수 있습니다.

`downloads/`에는 단일 HTML 실행 파일, 원본 소스 ZIP, 샘플 CSV, 사용안내가 들어 있습니다.
`dist/`는 모듈별 개발 소스입니다. 단일 HTML 실행에는 서버나 프로그램 설치가 필요하지 않습니다.

## 기능

- 유튜브·링크드인·인스타그램 KPI와 월별 SVG 추이 차트
- 연간 목표 달성률 및 전월 증감률
- CSV/XLSX 업로드와 전체 행 검증, 월·채널별 대체 저장
- 콘텐츠 일정 추가·수정·삭제
- HTML 보고서 및 실적 CSV 백업 다운로드
- 기간·채널 필터와 반응형 레이아웃

## 저장과 API 확장

데이터는 해당 브라우저 localStorage에 저장됩니다. 다른 기기와 동기화되지 않습니다.
브라우저 데이터 삭제 또는 HTML 파일 위치 변경 시 기존 데이터를 읽지 못할 수 있으므로 실적 CSV를 백업하세요.
`dist/repository.js`의 저장소 계약을 HTTP 어댑터로 교체해 향후 API 연동을 확장할 수 있습니다.

## 검증

Node.js가 있는 개발 환경에서는 `node tests/test.mjs`로 13개 데이터/저장 동작 검증을 실행할 수 있습니다.
JavaScript 구문 검사와 자동 검증은 통과했습니다.
실제 브라우저 클릭, 반응형 화면 실측 및 브라우저 XLSX 압축 해제 검증은 환경 제약으로 미완료입니다.
구형 XLS 및 암호화된 Excel은 지원하지 않습니다. 자세한 내용은 `downloads/사용안내.txt`를 확인하세요.
